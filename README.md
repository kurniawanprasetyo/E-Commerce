# VIVA E-commerce

A responsive lifestyle e-commerce storefront built with React, TypeScript, and Vite, inspired by the supplied visual reference.

## Requirements
- Node.js 20 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Playwright tests
```bash
npx playwright install chromium
npx playwright test
```

## Deployment
This is a frontend demo. Product data and cart state are client-side; no production backend or payment provider is connected. GitHub Pages deployment is configured with Vite base path `/E-Commerce/` in CI.
